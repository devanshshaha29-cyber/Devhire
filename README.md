# DevHire

DevHire is an AI-powered developer intelligence platform that analyzes a candidate's resume, GitHub projects, and target job description to identify strengths, missing skills, and a personalized path toward job readiness.

## Features

- User registration and JWT authentication
- Resume upload and skill extraction
- Target job analysis
- Skill matching
- GitHub repository analysis
- Proof-of-skill detection
- Candidate readiness analysis
- Personalized learning recommendations
- React dashboard
- Dockerized frontend, backend, and PostgreSQL

## Tech Stack
